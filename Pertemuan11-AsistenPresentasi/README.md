# Catatan Pertemuan 11: Aplikasi Asisten Presentasi

Pada pertemuan ini dipelajari perancangan antarmuka dan kontrol aplikasi asisten presentasi (timer presentasi):
- **Pengaturan Durasi**: Menggunakan kontrol `NumericUpDown` untuk menentukan durasi waktu presentasi (menit dan detik).
- **Kontrol Aksi Presentasi**: Tombol aksi untuk Mulai Presentasi, Ulangi durasi, dan Mode Ringkas.
- **Pengaturan Tampilan Selalu di Atas (Always on Top)**: Opsi CheckBox "Tetap di atas aplikasi lain" (`TopMost`) agar jendela aplikasi tetap tampak di atas slide presentasi saat berganti jendela.
- **Pemberitahuan dan Pintasan Akses Cepat**: Dukungan opsi audio berbunyi saat waktu habis serta tombol pintas keyboard (Ctrl+Alt+F9 untuk mulai/jeda, Ctrl+Alt+F10 untuk ulangi).

# Catatan Pertemuan 2: Komponen Visual

Pada pertemuan ini dipelajari perancangan antarmuka visual (UI) pada Windows Forms menggunakan komponen dasar:
- **Label (`lblNama`, `lblNIM`, `lblKOM`)**: Komponen untuk menampilkan teks statis sebagai petunjuk bagi pengguna.
- **TextBox (`txtNama`, `txtNIM`, `TextBox1`)**: Kotak isian tempat pengguna memasukkan data teks.
- **Button (`btnTampilkan`, `btnHapus`, `btnKeluar`)**: Tombol interaktif untuk memproses aksi program ketika diklik.
- **MessageBox (`MessageBox.Show`)**: Menampilkan kotak dialog pop-up berisi pesan sapaan beserta data Nama, NIM, dan KOM yang diinputkan.
- **Operator Penggabung String (`&`) dan `vbCrLf`**: Menggabungkan data teks serta membuat baris baru agar tampilan informasi tersusun rapi ke bawah.

# Catatan Pertemuan 5: Modul, Fungsi, dan Array

Pada pertemuan ini dipelajari pengelolaan struktur program menggunakan modul, sub/fungsi, dan array:
- **Module (`ModArray`)**: Berfungsi sebagai tempat penyimpanan fungsi, prosedur, dan variabel global yang dapat diakses dari seluruh form.
- **Prosedur dan Fungsi**:
  - `Sub TampilkanPesan`: Prosedur untuk menampilkan dialog pesan tanpa nilai kembalian.
  - `Function hitung`: Fungsi berparameter yang memproses logika perhitungan dan mengembalikan nilai.
- **Array 1 Dimensi**: Deklarasi dan inisialisasi kumpulan data linear (contoh: daftar nilai integer).
- **Array 2 Dimensi**: Deklarasi kumpulan data berdimensi banyak (baris dan kolom) untuk struktur data tabel/matriks.
- **Pengolahan Array pada UI**: Menampilkan elemen array ke dalam `ListBox` menggunakan perulangan `For` dan properti `Length`.
